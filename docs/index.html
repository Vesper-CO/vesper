New

Vesper Rust: Minecraft 26.3, without Java.

Vesper Rust runs Minecraft natively, rewritten in Rust. There is no Java to install or tune, so memory and Java settings simply do not apply. It is built on the open-source Horizon client, with Vesper’s own look and its own checks on top.

Built-in native mods

Native mods are Rust code compiled into the game itself, so they run as part of it. Vesper builds a hand-picked set in. They start switched off: turn each one on or off from the Mods page in the launcher, or in the game under Options > Mods.

Horizon’s mod library

Mods for Rust come only from Horizon’s own library, the one at playhorizon.dev/mods, because Java mods do not run in a Rust game. Every download is checked against the library’s size and SHA-256 before it touches your game folder.

Resource packs and shaders

The Modrinth library of resource packs and shader packs works in Rust too, from the same Mods page you already use. Older packs are offered when nothing is tagged for 26.3.

Checked, and private

Vesper verifies each Rust build’s signature and checksum before it runs, and looks for a newer build each time you play. The client does not ping Horizon’s servers: no usage heartbeat and no cosmetics service.

Discord Rich Presence

Show what you are playing on your Discord profile, in the launcher and in the game: singleplayer, multiplayer, hosting a world, even the dimension. It never shows server addresses or accounts, and one switch in Settings turns it off.

What you need

Windows 10 or 11, 64-bit, and a graphics card with Vulkan or DirectX 12. The first launch downloads the Rust build and prepares the game from your own Minecraft account, which takes a few minutes. Java instances keep working next to it.

Get started

Install in a minute.

  1. Download Vesper-Setup.exe and run it, then click Install.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  3. Open Vesper, go to Accounts, and sign in with the Microsoft account that owns Minecraft: Java Edition.
  4. Create an instance and press Play. For Rust, choose the Rust loader at 26.3. The first launch downloads the game, and Java for Java instances.
You need to own Minecraft: Java Edition. Vesper has no offline or cracked mode.
Questions

Good to know.

Does Vesper Rust replace the normal launcher?

No. Java instances and Rust instances live side by side in the same launcher. Pick Rust only for the instances you want to run without Java.

Can I use my Fabric or Forge mods in Rust?

No. Those are Java mods, and a Rust game cannot run Java code. Rust instances use mods from Horizon’s library, plus resource packs and shaders from Modrinth.

Why are the native mods switched off?

Native mods change the game itself, so Vesper leaves them off until you choose. Switch the ones you want on from the Mods page or in the game, and the choice sticks. A change applies the next time you start the game.

Is Vesper Rust made by Mojang?

No. Vesper is unofficial and is not approved by or associated with Mojang or Microsoft. The Rust client is built from the open-source Horizon project, under its MIT licence.
