Vesper
GitHub

A lighter way to play Minecraft.

Vesper is a small, fast launcher for Minecraft: Java Edition. Manage instances, install mods from Modrinth in one click, and launch Fabric, Quilt, Forge or NeoForge without fuss.

Download for Windows All versions

Windows 10 or 11, 64-bit. No admin rights needed.

Small and quick

An installer of a few megabytes that starts fast and stays light on memory.

Modrinth built in

Search mods, resource packs, shaders and modpacks. Dependencies are installed for you.

Instances

Separate versions, loaders, mods, memory and Java settings for every world setup.

Safe sign-in

You sign in on Microsoft’s own page. Vesper never sees your password, and tokens are stored encrypted.

Updates itself

New launcher versions download and install automatically.

Dark and light

Dark by default, with a light theme in Settings.

Install

  1. Download the Setup file and run it.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  3. Open Vesper, go to Accounts, and sign in with the Microsoft account that owns Minecraft: Java Edition.
  4. Create an instance and press Play. The first launch downloads the game and Java.
You need to own Minecraft: Java Edition. Vesper has no offline or cracked mode.
